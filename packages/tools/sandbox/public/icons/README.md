# PWA Icons for Babylon.js Sandbox

The PWA requires icon files to be created:

## Required Icons

Create the following PNG files in this directory:

1. **icon-192.png** - 192x192 pixels
2. **icon-512.png** - 512x512 pixels

## Recommendations

- Use the Babylon.js logo or a simplified version
- Icons should have a transparent or solid background (preferably matching the theme color: #2a2342)
- Icons should be square with the logo centered
- Consider using a "maskable" safe zone (the center 80% of the icon area) for important content

## Generating Icons

You can use tools like:

- [PWA Asset Generator](https://github.com/nicholasrobinson/pwa-asset-generator)
- [Favicon.io](https://favicon.io/)
- Adobe Illustrator / Photoshop
- Figma

Or convert the existing Babylon.js favicon at https://www.babylonjs.com/favicon.ico to the required sizes.
